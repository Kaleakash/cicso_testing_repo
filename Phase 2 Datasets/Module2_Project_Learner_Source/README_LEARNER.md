# Learner Reference Source — Secure NetPulse Devices API

Use this reference package after attempting the Module 2 Applied Project.

The included `main.py` must be identical to the trainer-validated source used for screenshots.

It demonstrates:
- public GET operations
- Pydantic models
- JWT login/token flow
- protected POST / PUT / PATCH / DELETE
- 401 and 404 behavior

Set `DEMO_USERNAME`, `DEMO_PASSWORD`, and `JWT_SECRET` in the environment before running.

Do not hardcode credentials or secrets.

Reviewed revision: JWT subject must match DEMO_USERNAME. Previous source hash screenshots reflect the original release.
